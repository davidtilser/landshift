# Repository instructions

- Use the existing Git author and committer identity from Git configuration. Never override that identity or require a specific name, email address, or GitHub account.
- Local development and preview servers may be started or restarted as needed during development. Always stop the task's local development and preview servers when development is finished, unless the user explicitly asks to keep one running.
- Write project documents in English, including specifications, research documents and implementation handoffs. Chat replies may follow the user's language.
