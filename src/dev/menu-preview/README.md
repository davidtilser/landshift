# Menu preview (temporary)

This preview is deliberately temporary: it mounts the landing screen at `/src/dev/menu-preview/index.html` against a fake globe that fills the viewport, logs every call to the console, and simulates the region pills the real globe will draw. Drag the fake globe horizontally to rotate it; pills show only within ±90° of the view longitude, enabled pills glow on hover, and "Coming soon" pills ignore clicks. A status box prints the fake globe's state. The preview owns the game handoff the way the real caller will; append `?fail-handoff` to exercise the load-failure path. Removal trigger: the landing screen is wired to the real globe in src/main.ts. Deletion list: `src/dev/menu-preview/`. Permanent code under `src/app`, `src/regions`, `src/scenarios`, `src/screens`, and `src/ui` must never import from `src/dev`.
